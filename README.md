# GH-FOSS-T1
Learn to make a commit and merge a PR

# How to make a commit 
1. Fork the repo and clone it.
```bash
git clone <url>
```
2. Make sure to use `git pull` to avoid merge conflicts. 
3. Make a new branch.
```bash
git switch -c <branch-name>
```
4. Edit the participant.md with your name and roll no.
5. Make a PR.
